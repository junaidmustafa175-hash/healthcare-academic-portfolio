# Healthcare & Academic Portfolio

Professional materials supporting applications to:
1. **Healthcare Management & Operations** (Service/Operations Manager, Clinical Governance, Practice Manager – NHS Bands 7–8d and private providers)
2. **Higher Education** (Lecturer, Senior Lecturer, Teaching Fellow, Module Leader in Healthcare Management, Public Health, Health Sciences, Business Administration)

## Structure
- `/cv/` – ATS-optimised CVs (management and academic versions)
- `/cover-letters/` – Tailored cover letter templates
- `/teaching/` – Teaching philosophy, module examples, assessment strategies
- `/operations/` – Case studies on operational improvements, governance, RTT/capacity work

## Usage
Link this repository in applications. Materials are written with strong action verbs and STAR-aligned examples ready for interview preparation.

**Note:** Populate with specific achievements as available. All content is designed for professional, authoritative presentation.
